The full pattern

I(θ) = I0 · (sin α / α)2 · (sin Nγ / N sin γ)2

α = π a sin θ / λ     γ = π d sin θ / λ

The first factor is the hump, set by the width of one slit. The second is the stripes, set by the slit spacing and the number of slits. They multiply, so the stripes sit inside the hump.

What each symbol means

λ
Wavelength of the light. This is the colour, 400 to 700 nm for visible light.
a
Width of each slit.
d
Distance between the centres of neighbouring slits. It is never smaller than a.
N
Number of slits. 1 is a single slit, 2 is a double slit.
D
Distance from the slits to the screen.
θ
Angle between straight ahead and the direction to a point on the screen.
x
Position on the screen, measured from the centre. For small angles x ≈ Dθ.
α
Phase term from the slit width, πa sin θ / λ. It shapes the hump.
γ
Phase term from the slit spacing, πd sin θ / λ. It shapes the stripes.
I
Intensity (brightness) at angle θ.
I0
Intensity at the centre of the pattern. It is set to 1 on the plot.
m
Order of a bright fringe. 0 is the centre, then ±1, ±2 and so on.
n
Number of a dark zero of the single-slit pattern: ±1, ±2 and so on.

Missing orders

A bright fringe can fail to appear when it lands on a dark zero of the single-slit pattern.

  1. Bright fringes sit where d sin θ = mλ.
  2. Dark zeros sit where a sin θ = nλ.
  3. If both happen at the same angle, d / a = m / n, so m = n · (d / a).

At that angle each slit sends no light, so there is nothing for the slits to add together.
